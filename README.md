# 🌞毎朝IT技術トレンド通知ボット

毎朝決まった時間に Qiita や Zenn の最新技術トレンド記事を自動取得し、Google Chat の指定スペースへ配信する自動化システムです。

---

## 1. 開発背景・目的
- **課題意識**: 若手エンジニアの情報収集習慣の不足や、「何をキャッチアップすればいいか分からない」という状態の解消。
- **目的**: 
  - 始業時に手軽に読める技術記事を共有し、チーム内の技術的会話や学習意欲を底上げする。
  - チャット上でのリアクション（スタンプやコメント）を通じた、アウトプット文化の土台作り。

---

## 2. システム構成・機能概要
```text
[Qiita API / Zenn RSS]
│ (最新記事を抽出)
▼
[Linuxサーバー (Ubuntu)] ──(cronで平日 08:30 JST に自動起動)
│ (Pythonスクリプトで整形)
▼
[Google Chat Incoming Webhook] ──> チャットスペースへ自動配信
```
### 主な機能
- **トレンド記事の自動抽出**:
  - Qiita: ストック数30以上の人気記事からランダム選出
  - Zenn: トレンドRSSから最新記事を選出
  - 片方が失敗した際の自動フォールバック処理を実装
- **定期配信**:
  - Linuxサーバーの `cron` を利用し、平日朝 08:30 に安定稼働。
- **安全なシークレット管理**:
  - `python-dotenv` を採用し、Webhook URLなどの秘匿情報を環境変数として安全に分離。

---

## 3. 技術スタック
- **言語**: Python 3.x
- **実行環境**: Linux サーバー (Ubuntu / AWS)
- **定期実行**: cron (JST)
- **主要ライブラリ**:
  - `requests` (APIリクエスト / Webhook送信)
  - `feedparser` (RSSフィード取得・解析)
  - `python-dotenv` (環境変数管理)

---
